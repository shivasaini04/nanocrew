# Code of conduct

We want this project to be a respectful place to work on software.

- Be kind and assume good intent. Disagree with ideas, not people.
- No harassment, discrimination, personal attacks or sexualised content.
- Do not publish other people's private information.
- Keep discussions on topic and constructive.

Maintainers may remove comments, issues or contributions that break these rules, and may block repeat offenders.
Report a problem by contacting the maintainers through a private GitHub message or the repository's Security
tab.
